# RedPhant Records Website

GitHub-ready static website for RedPhant Records.

## Files

- `index.html` — website
- `images/` — label logo and release artwork

## Deploying with Netlify

Connect this repository to Netlify. No build command is required; the site root is the repository root.

## Adding future releases

1. Upload the new artwork into `images/`.
2. Update the release entry in `index.html`.
3. Commit the changes.
4. Netlify will redeploy the site automatically when GitHub integration is enabled.

Keep artwork filenames simple and use relative paths such as `images/my-artwork.jpg`.
